# Naive-Bayes_Analiza


## 🎯 Features
- Object-Oriented Design
- Supervised Learning
- Classification using Naive Bayes
- Train/Test Split
- CSV Input Support
- Command-line UI

## 🏗️ Project Structure
- `NaiveBayesClassifier` – core classification logic
- `DataLoader` – CSV reading + splitting
- `CLI` – text-based user interface
- `Manager` – main coordinator

## 🐳 Docker Usage

docker build -t nb_classifier .
docker run -it nb_classifier
